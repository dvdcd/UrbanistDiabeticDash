Diabetic Dash

Real-time CGM display for the Adafruit Matrix Portal S3

Fresh Install

First time? Sets up the device from scratch. You'll re-enter your credentials.

Update

Already configured? Flashes new firmware only — credentials stay.

Install fails on the first attempt?
  1. The ESP32-S3 re-enumerates its USB port when it enters bootloader mode, which can break the first connection attempt.
  2. Easiest fix: just click Install (or Update) a second time — the device is already in bootloader mode and will flash successfully.
  3. Manual method: hold the BOOT button, press and release RST, then release BOOT — now click Install. The device starts directly in bootloader mode, no re-enumeration needed.

After a fresh install

  1. Connect the device to power via USB-C.
  2. On your phone or computer, join the WiFi network DiabeticDash-Setup.
  3. Open 192.168.4.1 in your browser and enter your WiFi credentials and Dexcom or Nightscout login.
  4. Click Save & Restart — the dashboard will appear within a minute.

Requires Chrome or Edge · USB connection to device · Source on GitHub
